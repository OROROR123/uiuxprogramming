# FocusDay - 하루 계획 설정

## 프로젝트 소개

- 주요 사용자: 하루의 할 일과 일정을 계획하고 정리하려는 사용자
- 사용자 목표: 하루 계획을 설정하고 할 일을 정리하며 완료 상태를 확인한다.
- 서비스 목적: 하루 계획을 세우고 할 일을 점검하는 과정을 연습하는 서비스
- 핵심 행동: 계획 제목과 조건을 설정한 뒤 할 일을 추가하고 완료 여부를 체크한다.
- 완료 조건: 계획 설정을 완료하고 체크리스트에서 할 일의 완료 상태를 확인한다.


## 8주차 결과물에서 추가·수정한 기능

기존 체크리스트의 입력 폼을 개선했다. 할 일 입력 시 글자 수와 조건 충족 여부를 표시하고, 메모 추가 체크박스를 선택하면 메모 입력창이 나타나도록 했다.

입력 조건을 충족하지 못하면 오류 문구를 표시한다. 제출 중에는 버튼을 비활성화하고 진행 상태를 안내하며, 성공과 실패 결과를 화면에 표시한다.

### 입력 조건

- 할 일: 필수 입력, 앞뒤 공백을 제외한 2~40자
- 메모: 선택 사항, 메모 추가를 선택한 경우 필수 입력, 최대 30자
- 같은 이름의 할 일이 이미 있으면 추가하지 않고 실패 안내를 표시한다.

## 사용자의 흐름

1. 계획 설정 안내를 확인하고 '설정 시작하기'를 누른다.
2. 계획 제목을 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 계획의 상세 정도를 선택하고 필요하면 점검 질문을 추가한다.
4. 제목, 상세 정도, 점검 질문 설정을 확인하고 수정하거나 완료한다.
5. 설정 완료 화면에서 체크리스트를 연다.
6. 할 일을 입력하고 필요하면 메모를 추가한 뒤 '할 일 추가하기'를 누른다.
7. 완료한 할 일을 체크하거나 삭제하고 완료 개수와 진행률을 확인한다.
8. 이전 화면으로 돌아가거나 새 계획 설정을 시작한다.

## 인터랙션 시나리오

### 1. 시작과 설정 안내

- 행동, 이벤트: 안내 확인 체크박스를 선택하고 '설정 시작하기'를 클릭한다. (change, click)
- 조건: 안내 확인 체크박스가 선택되었는가?
- 반응, 다음 상태: 선택 전에는 시작 버튼이 비활성화된다. 선택 후 버튼을 누르면 설정 안내 모달이 열린다.
  - '돌아가기' 또는 Esc를 누르면 안내 확인이 해제되고 이용 준비 화면에 남는다.
  - '안내 확인 후 시작하기'를 누르면 계획 제목 입력 단계로 이동한다.

### 2. 계획 제목 입력

- 행동, 이벤트: 계획 제목을 입력하고 '조건 선택하기'를 클릭한다. (click)
- 조건: 앞뒤 공백을 제거한 제목이 비어 있는가?
- 반응, 다음 상태: 비어 있으면 오류 문구와 테두리를 표시하고 입력창에 초점을 둔다.
  - 제목을 입력한 뒤 다시 '조건 선택하기'를 누르면 오류를 해제하고 다음 단계로 이동한다.

### 3. 계획 조건 선택

- 행동, 이벤트: 슬라이더로 상세 정도를 변경하고 점검 질문을 선택한다. (input, change, click)
- 조건: 점검 질문 추가 체크박스가 선택되어 있는가?
- 반응, 다음 상태: 상세 정도는 '간단하게·보통·자세하게' 중 선택한 값으로 표시된다.
  - 점검 질문을 추가하면 질문 개수 선택 항목이 나타나고 활성화된다.
  - 추가하지 않으면 질문 개수 선택 항목이 숨겨지고 비활성화된다.
  - '내용 확인하기'를 누르면 선택값을 확인 화면에 표시한다.

### 4. 이전 단계와 내용 수정

- 행동, 이벤트: '이전' 또는 '수정하기'를 클릭한다. (click)
- 조건: 사용자가 이전 단계로 돌아가거나 내용을 수정하려는 경우
- 반응, 다음 상태: 기존 값을 유지한 상태로 이전 단계로 이동한다.
  - 값을 수정하고 다시 진행하면 변경된 내용이 확인 화면에 반영된다.

### 5. 설정 완료와 다시 시작

- 행동, 이벤트: '설정 완료하기' 또는 '다시 설정하기'를 클릭한다. (click)
- 조건: 확인 단계에서 완료 버튼을 누르거나, 완료 단계에서 다시 설정 버튼을 눌렀는가?
- 반응, 다음 상태: 완료를 선택하면 설정 완료 안내 화면을 표시한다.
  - '다시 설정하기'를 누르면 기존 계획과 체크리스트를 초기화하고 첫 입력 단계로 이동한다.
  - 체크리스트를 열면 할 일을 관리하는 화면으로 이동한다.

### 6. 할 일과 메모 추가

- 행동, 이벤트: 할 일을 입력하고 필요하면 메모를 추가한 뒤 '할 일 추가하기'를 클릭한다. (input, change, submit)
- 조건: 할 일을 2~40자로 입력했는가? 메모 추가를 선택했다면 메모를 입력했는가?
- 반응, 다음 상태: 입력 중에는 글자 수와 조건 충족 여부를 표시하고, 조건을 충족하면 입력창 색상이 변경된다.
  - 메모 추가를 선택하면 입력창이 나타나고, 해제하면 숨겨지고 비활성화된다.
  - 입력 조건을 충족하지 못하면 오류 문구를 표시하고 해당 입력창에 초점을 둔다.
  - 제출 중에는 진행 문구를 표시하고 제출 버튼을 비활성화한다.
  - 정상적으로 추가되면 성공 메시지를 표시하고 입력 내용을 비운다.
  - 같은 할 일이 이미 있으면 실패 메시지를 표시하고 입력 내용을 유지하여 다시 시도할 수 있도록 한다.

### 7. 할 일 완료와 삭제

- 행동, 이벤트: 할 일의 체크박스를 선택하거나 '삭제' 버튼을 클릭한다. (change, click)
- 조건: 완료한 할 일이 있는가? 모든 할 일을 완료했는가?
- 반응, 다음 상태: 체크박스를 선택하면 완료 개수와 진행률이 변경된다.
  - 모든 할 일을 완료하면 완료 안내 메시지를 표시한다.
  - 체크를 해제하거나 새 할 일을 추가하면 완료 상태를 다시 계산한다.
  - '삭제' 버튼을 누르면 해당 할 일이 목록에서 제거되고 진행률이 변경된다.

### 8. 이전 화면과 새 계획 설정

- 행동, 이벤트: '설정 완료 화면으로 돌아가기' 또는 '새 계획 설정하기'를 클릭한다. (click)
- 조건: 이전 화면으로 돌아가거나 새로운 계획을 설정하려는 경우
- 반응, 다음 상태: 이전 화면으로 돌아가면 기존 체크리스트와 완료 상태를 유지한다.
  - 체크리스트를 다시 열면 이전에 추가한 할 일을 확인할 수 있다.
  - 새 계획 설정을 선택하면 기존 계획과 체크리스트를 초기화하고 첫 입력 단계로 이동한다.

## 테스트 결과 및 확인 순서

1. 정상 흐름: 시작부터 계획 설정 완료와 체크리스트 진입까지 단계 이동 확인
2. 빈 값 제출: 할 일을 입력하지 않고 추가했을 때 오류 안내와 제출 차단 확인
3. 잘못된 값: 한 글자만 입력하거나 공백만 입력했을 때 오류 안내 확인
4. 오류 수정: 2자 이상 입력하면 오류가 해제되고 입력 상태가 변경되는지 확인
5. 조건부 입력: 메모 추가 선택과 해제에 따라 입력창 표시 및 비활성화 확인
6. 메모 검증: 메모 추가 선택 후 내용을 입력하지 않았을 때 오류 안내 확인
7. 정상 제출: 할 일과 메모가 목록에 추가되고 성공 메시지가 표시되는지 확인
8. 제출 중 상태: 진행 문구와 버튼 비활성화로 중복 제출이 차단되는지 확인
9. 실패와 재시도: 같은 할 일을 다시 추가했을 때 입력값이 유지되고 수정 후 재시도할 수 있는지 확인
10. 완료·삭제: 체크박스 선택, 전체 완료 메시지, 삭제 후 진행률 변경 확인
11. 이전·초기화: 이전 화면 이동 시 값 유지, 새 계획 설정 시 입력값과 안내 문구 및 버튼 상태 초기화 확인
12. 브라우저·모바일: 모달, 탭, 다크 모드와 1100px / 768px / 390px 화면 조작 확인
