## 6주차 이벤트 및 탭 UI 추가

 ## 1. 구현한 이벤트
  click: 다크 모드 전환 및 버튼 문구 변경
  input: 닉네임 입력 시 글자 수 표시
  change: 개인정보 동의에 따라 안내 문구와 버튼 상태 변경 
 
 ## 2. 화면 변화
  classList로 화면 스타일 변경
  textContent로 안내 문구 변경
  disabled로 버튼 활성화 및 비활성화

 ## 3. 탭 UI 추가
  3개의 탭을 추가하여 기능별 콘텐츠 전환
  선택된 탭 강조 및 나머지 콘텐츠 숨김
  aria-selected와 hidden으로 탭 상태 관리
